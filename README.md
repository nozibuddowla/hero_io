# Hero IO

**Description:** A responsive app-store UI built with React + Vite. Browse top apps, view app details with rating charts, install/uninstall apps (localStorage), and manage your installed apps.

**Live Preview:** [https://hero-io-no.netlify.app/](https://hero-io-no.netlify.app/)

**Technologies**

- React, React Router
- Vite
- Tailwind CSS
- Recharts
- react-toastify

## Run locally

1. `npm install`
2. `npm run dev`
3. `npm run build`
4. `npm run preview`

## Features

- Responsive UI for mobile/desktop
- All Apps / App Details / My Installation pages
- Live search (case-insensitive)
- Sort by downloads (High-Low / Low-High)
- Install/Uninstall with localStorage persistence
- Recharts for review visualization
